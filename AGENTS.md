# Agent Guidelines for the QEMU-mod Project

This is a fork of the upstream QEMU source code, and none of the changes made to this
repository are intended to be submitted upstream. However, all changes made to this
repo must comply with the license terms applicable at the point of divergence.


You are allowed to merge in changes from upstream to synchronise the code base in this 
repository with enhancements and fixes made upstream, however, you must respect the
relevant licenses. If there is a merge conflict, presume that this forked repository is 
a superset. If upstream functionality contradicts with local functionality in this 
forked modified set, the local functionality should win. Valid exceptions to this rule 
can be made, but they need authorisation of the user beforehand.

When merging changes, do not merge in upstream repository guidelines or restrictions. 
We have deliberately changed these for our fork, and the changes in this fork are authorative
for this fork.
